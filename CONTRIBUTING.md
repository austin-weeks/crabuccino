# Contributing to Crabuccino

Thank you for considering contributing to Crabuccino!

## How to Contribute

First, take a look at our [issues](https://github.com/austin-weeks/crabuccino/issues) tab. If you see an open issue that you'd like to tackle, please leave a comment expressing interest and it will be assigned to you. Feel free to ask any questions about the task!

If you'd like to report a bug, please open an issue describing the problem. If you plan on contributing a fix, let us know when creating the issue and we'll assign it to you.

If you find yourself wishing for a feature that doesn't exist, you are probably not alone. There are bound to be others out there with similar needs. Open an issue and describe the feature you would like to see, why you need it, and how it should work.

AI-generated contributions are not allowed. This project is for humans, by humans!

## Review Process

Maintainers review pull requests on a regular basis. In most cases there will be requested changes to your code. This is normal, and is in no way an indication that your work is of poor quality! We want Crabuccino to be the best it can possibly be, and we want to build up developers in the process!

## Development

To develop Crabuccino, you'll need [Node JS](https://nodejs.org/en) and [`pnpm`](https://pnpm.io).

You can run all checks locally - these are the same verification steps that will be run against your PR:

```sh
pnpm run local-ci
```
